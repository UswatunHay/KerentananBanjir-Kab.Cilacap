# KerentananBanjir-Kab.Cilacap
Kabupaten Cilacap memiliki kerentanan banjir tinggi di bagian tengah- selatan, terutama sekitar Segara Anakan karena berupa dataran aluvial rendah yang dilalui banyak sungai besar dan terpengaruh pasang surut. Curah hujan tinggi, sedimentasi, dan alih fungsi lahan memperparahnya, sedangkan wilayah utara yang berbukit lebih rendah kerentanannya.
